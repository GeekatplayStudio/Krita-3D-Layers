Geekatplay 3D Layers

Turn a layer into a 3D model, pose and light it, and place it in your image as a layer you can change any time.

Start

  1. Show the docker: Settings › Dockers › 3D Layers.
  2. No 3D service yet? On the Create tab click Try the sample model.
  3. To make your own models, open Settings in the docker and add a key for Meshy, Tripo or Hitem3D, or the address of your ComfyUI.
  4. Select a layer (a cut-out object on a transparent background works best) and click Generate 3D model.
  5. When the job says Ready, click Pose & place. The 3D editor opens in its own window, over your image. Pose, light, and click Place in Document.
  6. Later, select the layer and click Edit pose & light (or Tools › Scripts › Edit 3D Layer) to change it.

The 3D editor runs in a browser window (Microsoft Edge or Google Chrome when available), because Krita plugins cannot show 3D themselves. It talks only to Krita on this computer.

Models are kept in a library shared with Geekatplay 3D Layers for Photoshop. Full guide: docs/USER_GUIDE.md in the project.
